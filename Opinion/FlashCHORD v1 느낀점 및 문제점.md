요약: 20개의 training set 중 10개에선 성공적으로 레퍼런스를 재현 했지만 두 개의 물체가 등장하는 경우 레퍼런스 문제, 강화학습 문제가 각각 5개씩 관찰됐다.

물체가 여러 개인 경우에 대해서 별도의 처리가 없다는게 가장 큰 문제점이라고 생각한다. Issac Lab 환경의 reward 항에는 relative pose를 다루는 보상항이 있는데(기본값은 꺼짐 상태), MuJoCo warp를 환경으로 하는 FlashCHORD 에는 기본으로 제공되는 부분이 없다. 두 물체, 더 나아가 n개 물체에 대해 사용할 수 있는 옵션이 있으면 좋을 것 같다.

접촉 제약 버퍼(`njmax`)의 기본 크기가 512인데, 이번 실험에서 최대 651의 접촉이 발생하는 것을 확인했다. 

속도는 한 clip, 250M steps, 4096 envs 을 기준으로 약 2.5시간이 소요된다.
