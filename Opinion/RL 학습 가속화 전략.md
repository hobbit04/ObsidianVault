RL 성능을 올리기 위해 고려했던 두 물체의 상대 pose 보상은 없어도 될 듯. 포즈만 잘 나오면 전반적으로 높은 성능을 보이는 것을 확인함. 

전이학습 전략
1. 클립에서 검출된 object mesh를 판별함
2. 기존에 봤던 mesh라면 해당 mesh에 대응되는 backbone 신경망에서 시작하도록 함
3. Actor는 불러오고, Value는 랜덤 스타트. task가 다르기 때문

현재 보상항

| 항                                   | 가중치      | 무엇을 재나                                                                                                                                             |
| ----------------------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `object_keypoints`                  | **+20**  | 물체 좌표계 ±X, ±Y, ±Z 방향 **1 m** 지점 6개의 위치 오차(var 0.1). 1 m 떨어진 점이라 회전 0.1 rad가 10 cm 오차가 되므로 사실상 **회전에 매우 민감**합니다. 물체 수와 키포인트 수로 평균합니다.               |
| `contact_wrench_support`            | **+10**  | 레퍼런스 접촉으로 만든 렌치 지지(어느 방향으로 물체를 밀거나 잡을 수 있는지)를 시뮬레이션 접촉이 ±10% 안에서 재현하는 정도. **레퍼런스 접촉은 사람 손(MANO) 접촉 표시(1 cm 기준)에서 나옵니다.** 이걸 2cm로 바꿔보는 실험 진행 중(c20) |
| `hand_keypoints`                    | +0.25    | 손바닥과 손가락 끝마디 위치의 레퍼런스 추적(var 0.1)                                                                                                                  |
| `hand_joint_pos`                    | +0.25    | 손가락 관절각 추적(var 1.0)                                                                                                                                |
| `missed_contact`                    | −1       | 레퍼런스가 요구한 렌치 방향 중 시뮬레이션이 만들지 못한 비율                                                                                                                 |
| `unintended_contact`                | **−10**  | 레퍼런스가 접촉을 요구하지 않은 물체에 닿은 비율, 그 접촉 지지 크기의 제곱                                                                                                        |
| `termination`                       | **−100** | 종료된 스텝                                                                                                                                             |
| `action_rate_l2`                    | −0.005   | 행동 변화량                                                                                                                                             |
| `action_l2`                         | −0.002   | 행동 크기                                                                                                                                              |
| `contact_force_l2`, `force_closure` | 0 (꺼짐)   | 접촉력 크기, force closure                                                                                                                              |
1. force_clousre 켜보기
2. 레퍼런스 접촉 범위 넓혀보기(진행 중)
3. `hand_space` 정의하고 레퍼런스에서 손이 물체를 잡을 때, `hand_space` 안에 해당 물체가 없다면 음의 보상 주도록 새로운 보상항 추가하기
4. `relative_object_pose` 정의해서 물체가 두 개인 경우 두 물체의 상대거리 측정해서, 레퍼런스의 상대거리와 유사하도록 설정. 이때 무게중심끼리만 비교하면 안되고(회전이 있어서) 두 물체의 법선 벡터를 구한 후 두 벡터의 각도도 따라가도록 보상 설정.
