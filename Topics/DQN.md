## Introduction
---
- 기존의 *Q-learning* 방식을 개선한 Deep Q-Network(DQN)을 개발했으며, 이는 deep convolutional network를 기반으로 사용한다. 
- 문제: Classic Atari 2600 games
Q 함수의 정의와, 이를 이용한 강화학습 방법은 이미 존재했지만 학습 과정에서의 **문제점**을 해결할 수 있었다.

### 기존 방식의 한계
1. 관측 데이터들의 시간적 상관관계
2. Q 함수가 변하면 데이터 분포가 바뀜
3. (Q 함수가 변하면) Q 값과 타깃 값의 상관관계가 바뀜
의 원인들로 학습이 안정적이지 않고, 심지어 발산하는 문제가 있었다. 먼저 해당 원인들이 문제가 되는 이유에 대해서 생각해보자.

먼저 **관측 데이터들이 시간적으로 상관이 있다** 는 말은, 강화학습에서 사용하는 데이터, 즉 *state*들이 시계열 데이터라는 의미다. $\{s_t, s_{t+1}, s_{t+2}\}$는 순서가 달라지면 다른 데이터가 되는 등, 독립적인 샘플링이라는 가정을 사용할 수 없게 된다. 이게 문제인 이유는 대부분의 학습 방식에서 사용하는 데이터는 i.i.d, 다시 말해 Independent and Identically Distributed 가정을 사용한다는 것이다. 모델은 한번에 전체 데이터를 보지 않는다. 대신 배치(batch), 또는 미니 배치(mini-batch) 단위로 샘플링을 해서 오차와 기울기를 계산한 후 신경망의 파라미터를 조정한다. 이때 샘플링을 무작위로(i.i.d 가정을 만족하게) 하지 않으면 결과가 편향된다거나, 분산이 커지는(즉 수렴하기 어려워지는) 문제가 발생한다. 그 이유는 통계학 중 correlation에 관한 내용을 공부해보면 알 수 있다. 

정리하자면 *샘플의 상관관계(correlation, $\rho$)가 큼* -> *학습에 사용하는 데이터의 gradient 분산이 큼* -> *Gradient의 분산이 크면, 학습시 error의 상한선이 커져서 학습이 잘 수렴하지 않음* 의 과정으로 문제가 발생한다. 

두 번째 이유인 **Q 함수가 변함에 따라 데이터 분포가 바뀌는** 이유는 이해하기 어렵지 않다. 에이전트의 정책은 Q 함수를 최대화 시키는 greedy 정책이다. 따라서 Q 함수가 바뀐다는 것은 곧 정책이 바뀔 수 있음을 의미하고, 정책이 바뀌면 당연히 이어지는 state도 달라질 것이다. 그런데 이게 왜 문제라는 걸까?
**그 이유는** Q 값의 타겟을 보면 알 수 있다. Q-learning은 정책을 학습하는 방법이 아니라, 상태과 행동에 따른 보상을 예측하는 Q 함수를 학습하는 것임을 상기하자. 이때 Q 함수는 어떤 타겟을 목표로 파라미터의 조정이 일어날까? 바로 *보상 + 다음 상태에서 얻을 수 있는 최대 Q 값* 을 목표로 한다. 수식으로는 $$r+\gamma \cdot \text{max}_{a'}Q(s',a')$$으로 나타낼 수 있다. Q 함수는 현재 상태와 행동에 따라 값을 내놓는 함수로, 심층 신경망으로 구현이 되어있다. 이 함수가 수렴을 해야 하는데, 타겟에 가까워지도록 Q를 조정하면 다시 타겟의 목표가 달라진다(목표에 자기 자신이 있기 때문). 운이 좋다면 수렴을 할 수도 있지만 발산할 우려가 있다. 복잡한 환경의 경우, 매우 높은 확률로 발산하게 된다. 

마지막으로 **Q 함수가 변함에 따라 Q-value와 target-value의 상관관계가 바뀐다**는 말은 두 번째 이유와 크게 다르지 않다. 

### 해결책 제시
위의 문제들을 해결하기 위해, 이 논문에서는 몇 가지 새로운 방식들을 제시한다.
1. Experience replay 사용 <- NFQ 방식의 한계를 개선하고자 도입한 방법. 
2. Q의 target value를 일정 기간 고정해서 업데이트
먼저 Experience replay에 대해 설명하겠다. 매 time step 마다 얻게 된 새로운 데이터를 튜플로 나타내면 다음과 같을 것이다. $$(s_t, a_t, r_t, s_{t+1})$$차례대로 time step t에서의 상태, 행동, 보상, 그리고 다음 상태를 나타낸다. 이러한 튜플을 이제 *experience*라고 부르자. 기호로는 $e_t$와 같이 나타낸다. 그러면 학습이 진행됨에 따라 여러 $e_t$가 생성되므로 이를 일종의 데이터 셋으로 생각할 수 있다. 즉, *experience*를 저장하는 데이터 셋 $D$를 만들고 학습은 $D$에서 uniform하게 샘플링 된 데이터들, 다시 말해 mini-batch를 이용해서 수행하는 것이다. 

- [ ] 질문: 그럼 초기 experience 들이 후반에 비해 상대적으로 학습에 적용될 확률이 높을텐데, 이건 문제가 되지 않나?

다음으로 Q를 업데이트 할 때, target value를 고정시킨다는 부분을 살펴보자. 
우선, Q함수는 파라미터로 다음 세가지 속성을 받는다. State, Action, 그리고 모델 파라미터($\theta$)다. 여기서 모델 파라미터는 보통 주어지고, state와 action이 어떻게 되냐에 따라 다른 가치(Q) 값을 주기 때문에 수식으로는 다음과 같이 쓴다. 
$$Q(s, a; \theta)$$
세미콜론(;) 으로 구분된 오른쪽은 '주어진', 'given' 정도의 뜻으로 볼 수 있다. Q의 target value를 고정한다는 말은 여기서 모델 파라미터를 하나로 고정한다는 것이다. Loss를 계산하고, 그 기울기에 따라 $\theta$가 바뀔텐데 그때마다 Q가 달라지면 곤란하니 고정하는 것이라고 했었다. 이 문장은 loss 함수의 수식을 보면 이해하기 쉽다.
$$\mathcal{L}_{i}(\theta_i)=\mathbb{E}_{(s,a,r,s') \sim U(D)} \left[ (r+\gamma  \text{ max }_{a'}Q(s',a';\theta_i^-) - Q(s, a;\theta_i))^2 \right]$$
여기서 $\theta_i^-$는 매 C iteration에만 업데이트가 되고 그 외에는 고정이다. 물론 $r+\gamma Q$가 target으로, Q가 근사해야 하는 목표이다. 

## Methods
---
### 전처리
1. 현재 프레임과 이전 프레임 중 max 값을 갖는 픽셀값을 사용함. Atari 2600 환경에는 flickering 이라는, 일부 객체는 짝수번에만, 일부 객체는 홀수번에만 등장하는 현상이 있기 때문.
2. RGB 채널에서 Y-channel, 다시 말해 휘도(Luminance) 채널만을 추출해 흑백 이미지로 만듦. 또한 원래 210 x 160 크기의 화면을 84 x 84 로 변형시킴(CNN 사용). 
3. 프레임 m=4 개를 쌓아서 하나의 state 으로 만듦. 
-> 전처리 이후 state의 크기 = 84 x 84 x 4
논문에선 위의 세 과정을 수행하는 함수를 $\phi(state)$ 함수로 나타낸다. 여기서 함수의 입력 값은 raw 게임 프레임 데이터이고 출력 값은 신경망의 input으로 사용될 수 있는 state이다.

위의 신경망 구조는 $Q$ 함수를 parameterizing 하고 있다. 입력으로는 $\phi$를 거쳐 전처리된 state($s$)이 들어가고, output으로는 총 action($a$) 개수 만큼의 채널이 존재한다. 신경망 자체는 $\theta$ 이고, 각 채널의 output이 주어진 s에 대해 a를 했을 때의 Q 값을 의미한다. $Q(s, a; \theta)$ 라는 식으로 Q 값을 표현했던 것을 생각해보면, 위의 다이어그램에는 모든 필요한 변수들이 포함된 것을 알 수 있다. 
이 외에도 다른 방법으로 $Q$ 함수를 parameterizing 할 수 있다고 하지만, 이 방식의 장점은 한번의 forward pass로 모든 actions 에 대한 $Q$ value를 알 수 있다는 것이다. 

위의 구조로 Q 함수를 표현한 다음, 학습 단계에선 target(보상 + 감가율 * 다음 상태에서의 최대 Q값)에 가까워지도록, 추론 단계에서는 최대 Q 값을 갖는 액션을 선택하도록 사용할 수 있다. 물론 추론 단계에서는 신경망을 변화시키지 않고 사용한다. 

이 논문에서는 Atari 2600의 다양한 환경들에 대해 동일한 아키텍쳐를 사용했음을 강조한다. 다만 최종 출력층은 게임 환경마다 사용하는 actions의 수가 다르기 때문에 달라진다(minimal prior knowledge). 이 때문에 각 환경마다 새로 학습을 진행시킬 수밖에 없다고 한다.
